# WeatherNow 🌤️

**WeatherNow** is a mini React project that allows users to search for current weather information of any city. It fetches real-time data from the **OpenWeatherMap API** and displays it in a clean, interactive card layout with vibrant visuals and icons representing different weather conditions.

website is live at- https://urdharesh.github.io/WeatherNow/

---

## 🔹 Features

- Search for weather by **city name**.
- Displays:
  - Current **temperature** 🌡️
  - **Humidity** 💧
  - **Min and Max temperature**
  - **Feels like temperature**
  - **Weather description** (haze, sunny, rainy, etc.)
- Interactive **icons** for weather conditions:
  - ☀️ Sunny
  - ❄️ Cold
  - 🌧️ Rainy
- Stylish **cards with gradient backgrounds** and hover animations.
- Responsive design, works on both **desktop and mobile**.
- Funky and playful **font styling** for a modern UI.

---

## 🔹 Technologies Used

- **React.js** – Frontend library for building UI.
- **Material-UI (MUI)** – For pre-built responsive components (Card, Typography, Icons, Button).
- **OpenWeatherMap API** – Fetches real-time weather data.
- **CSS3** – Custom styling with gradients, hover effects, and funky fonts.
- **JavaScript (ES6)** – Logic and async API calls.
